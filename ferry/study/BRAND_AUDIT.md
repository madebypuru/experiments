## 2. Decisions in force, with where they are written

### Logo
- Stepped butterfly mark, "two shores meeting". `BRIEF.md`, `README.md`, memory `ferry-brand`.
- Construction: mark 1.63A tall, 0.35A above ascender, 0.28A below baseline, 0.74A gap to the first letter. `README.md`.
- Bleed amount locked ("this amount"). `README.md`, memory `ferry-brand`. Clean SVG at 32 px and below.
- Clear space half the mark's width; minimum 16 px mark and 96 px lockup. Only in `system/LATER.md` (draft, not adopted).

### Wordmark and Ferry Sans
- Lowercase "ferry" in Ferry Sans Bold, spacing 35/33/6/1. `README.md`, memory `ferry-sans`.
- Ferry Sans is a modified TeX Gyre Heros under the GUST licence. Renamed, manifest in `type/README-FerrySans.txt`.
- Never base a shipped font on Helvetica Neue.

### Colour
- Eight colours: Paper `#F2EEE6`, Ink `#1B262B`, Harbour `#2C454B`, Sea glass `#6B8A94`, Mist `#C9CDBD`, Stone `#D2A57F`, Sea grass `#7D8F69`, Signal `#D2602C`. `system/SYSTEM.md`.
- Paintings may be any colour; everything around them uses only these. Text is Ink on light, Paper on Harbour and Ink. Signal appears once per view. `SYSTEM.md`.
- Extra values used in code but not in SYSTEM.md: `--mute #5E6A6E` and `--pen #22304A` (postcards, Swiss). Undocumented.

### Type voices (`type/VOICES.md`)
- Bodoni Moda: stamp value only (the number, with italic units).
- Monsieur La Doulaise: one place name per print piece, 40 px / 18 pt and up, ink on paper only.
- Ferry Sans: every headline (Bold, sentence case, six words or fewer, -5 percent tracking, with the bleed), body, ticket caps, UI numbers.
- A real pen hand: postcard message only, never a font.
- At most three levels per piece; script and serif never side by side at similar size.

### Grid and formats
- Social and slides: Swiss grid, 10 px baseline, 140 px modules, 20 px gutters. 4:5 is 1080x1350 (6x7 modules). 16:9 is 1920x1080 (11x6). No 9:16. T1 to T7 type scale. Lockup at 40 px tall as sign-off. `study/SWISS_GRID.md`, memory `ferry-layout-rigour`.
- Painting edge: palette-knife edge, quiet. `SWISS_GRID.md` principle 7, `PRINT_POSTCARDS.md`.
- Draft only: 8 px grid, 12/8/4 columns, bento with 24 px radius, X header 1500x500, X post 1600x900, OG 1200x630, ticket 2:1, stamp 4:5, postcard 3:2. `system/LATER.md`.
- Postcard 6x4 in at 300 ppi (1800x1200). Only in `postcard-01.html`.

### Print presentation
- Show only the object. No corner labels, counters, credits or explainer lines. Memory `ferry-no-extra-presentation-text`, `PRINT_STAMPS.md`.
- Close-up where the paper bleeds off the frame, soft light from the top left. `PRINT_STAMPS.md`.
- Presentation rules for mockups (one hero, real ground, one light, no platform chrome). `MOCKUP_PRESENTATION.md`. Not yet applied; the mockups it criticises are still the only ones.

### Shadows
- Barely visible. Stamp contact blur about 0.9, offset (0.7, 1), alpha 0.16, plus alpha 0.05 soft. Loose paper contact 0.2 and ambient blur 26 at 0.16. Faint light rim on the lit edge. All shadows fall away from the top-left light. Memory `ferry-quiet-shadows`; reference code `shStamp`/`shEnv` in `stamp-01.html`. Not written in any file under `ferry/`.

### Mark in print
- Bleed when seen in colour, blind emboss as a maker's mark, rubber stamp for events. No wax seal. One treatment per piece, two at most. Crisp mark stays in product and app icon. `PRINT_TO_UI.md`.
- Emboss is physically simulated; tuned defaults (9.5 mm, -0.4 degrees, light az 135 el 32, depth 0.08, shoulder 0.4, dome 0.37, ambient 0.36, shadow 0.68/0.8, highlight 0.32/6.4). `PRINT_TO_UI.md`, `emboss.js`, memory.

### Stamps and postcards
- Stamp: faithful anatomy, value is crossing time (41s), stepped notch edge, gouache for heroes and one-ink line for small sizes. `PRINT_STAMPS.md`. The one-ink line version does not exist yet.
- Postcard: four front formulas to design then pick; back has message plus facts table. `PRINT_POSTCARDS.md`. Only some fronts built; no pick recorded.

### Motion
- Calm. Click ripples are two faint broken-dab rings (strength about 0.5). Boats rock gently. Faster ferry departure was the one complaint. Memory `ferry-grown-up-gouache`. Not in any file under `ferry/`.
- Weather as state language (clear for normal, rain for incidents). `BRIEF.md`, `APPLYING_TO_FERRY.md`.

### Image sourcing and look
- Sources come from Pinterest photos run through Paint. No AI image generation; Codex image gen only as last resort. Memory `ferry-image-sourcing`. Not in any file under `ferry/`.
- Imagery must be grown-up gouache, painterly depth, not flat cartoon. Memory `ferry-grown-up-gouache`.
- Real photos allowed for presentation only. `BOARD_STUDY.md`.

### Voice
- Calm, plain-spoken. No em dashes, exclamation marks or emoji. Numbers over adjectives. Working line "Safe passage between chains." `BRIEF.md`.

### Contradictions between files

1. **Where serif is used.** `BRIEF.md` says serif for titles and display. `type/README-FerrySans.txt` and memory `ferry-sans` say display headlines are set in the brand serif. `APPLYING_TO_FERRY.md` puts the header line in the serif. `VOICES.md`, memory `ferry-brand` and `SWISS_GRID.md` say the serif is for the stamp value only and all headlines are Ferry Sans. VOICES is the later decision (user call); the others are stale.
2. **Main medium.** `BRIEF.md` and `APPLYING_TO_FERRY.md`: watercolour main, gouache a test accent. Memory `ferry-grown-up-gouache` and every painting made since: gouache. The logo wash is watercolour-style.
3. **Grid.** `LATER.md` (8 px, 12 columns, bento) versus `SWISS_GRID.md` (10 px, 140 px modules). `LATER.md` is parked, so the web has no adopted grid; `README.md` still lists the "grid and spacing" as part of the core system, which `SYSTEM.md` says is not done.
4. **Formats.** `POSTER_GRIDS.md` decisions list 4:5 and 9:16. `SWISS_GRID.md` and memory drop 9:16 and add 16:9. `MOCKUP_PRESENTATION.md` allows 9:16 "only when asked". `LATER.md` formats (X header, X post, OG) are not in the Swiss system at all.
5. **Bleed off the page.** `SWISS_GRID.md` principle 7 says nothing bleeds off the page, yet layouts 2 and 3 in the same file say the painting "bleeds off the page" or "off three sides". `BRIEF.md` and `LATER.md` also call for full-bleed paintings.
6. **Label tracking.** Ferry Sans README: caps labels +14 to +16 percent at 10 to 12 px. `VOICES.md`: ticket caps +20 to +25 percent. Swiss T7: +18 percent at 15 px.
7. **App icon.** `LATER.md` says Harbour field with a Paper mark. The exported icon is the bright wash, and the sheet's dark variant is near-black. `PRINT_TO_UI.md` rule: crisp mark in the app icon, but the exported icon is the bleed version.
8. **Mark in print versus Swiss.** `PRINT_TO_UI.md`: bleed mark when shown in colour, crisp only in product. `SWISS_GRID.md` signs off every layout with the clean lockup, and layout 1 uses a crisp mark window. Stated as an exception only for the window ("because it's the logo").
9. **Pen hand.** `VOICES.md` and `PRINT_POSTCARDS.md`: a real pen hand, never a font. The postcards use the font La Belle Aurore (see 4).
10. **Logo description in README.** Root `README.md` (modified, uncommitted) says Helvetica Neue Bold. `ferry/README.md` says Ferry Sans Bold. `ferry/README.md` also says only the logo is done; much more exists.
11. **Palette applied to the logo.** `SYSTEM.md` says the wash is repainted in the palette; the hero, icon and sheet still show the original.
12. **Process.** `BRIEF.md` says one touchpoint at a time with a reference from the user each. Memory `ferry-orchestrator-role` says the main session directs and agents build. Parallel sessions have built stamps, postcards, posters, mockups and type at once.

## 4. Placeholders and risks

**Other people's images (the largest risk).**
- Every painting in the brand is a Paint rendering of a Pinterest photo: lighthouse, rowboats, ferry arrival, harbour fire, cabin windows. Sources and photographers are not recorded anywhere. The raw photos sit in ignored `ferry/assets/refs/`. `c05-3x1.jpg` is an unpainted photo of a real ferry with a legible hull name.
- `SWISS_GRID.md` itself says the posters "render locally only until Ferry has its own paintings."
- Licence status of the sources is unknown. Nothing on disk is cleared for publication. The BRIEF's goal is a public pitch.
- All stamps, postcards, posters and animations depend on these.

**Uncommitted and ignored.**
- All of `ferry/` is untracked: no history, no backup, one deletion from loss. The user's note about a parallel session committing a test file to a public repo points the other way: committing `ferry/` needs care, because pages reference ignored paths.
- All imagery, the 12 poster renders, postcard PNGs, both interactive studies and 130 MB in total live only in ignored `ferry/assets/`. Not backed up by git. Deleting `.test` breaks `swiss.html`, `mockups.html`, both stamps and both postcards.
- `paint/index.html` and root `README.md` edits are uncommitted and not Ferry-owned in the log.
- Pages need a server rooted at `experiments/` (absolute `/paint/.test/...` and `/ferry/...` paths). Opening files directly shows broken images.

**Duplicates and divergence.**
- `print/knife.js` is a copy of `paintOn` in `print/swiss.html`. They can drift apart.
- `print/lighthouse-live.js` is a wrapped copy of the lighthouse study logic in the ignored folder.
- `src/glyphs.js` and `src/glyphs.json` hold the same data; both are generated, so rebuild both.
- `src/butterfly-mark.svg` (Figma export) and `export/ferry-mark-clean.svg` are different files for the same mark; which one is source is not stated.
- Stamp 01 exists as `stamp-01.html` (static, also the shadow reference) and `stamp-web.html` (live). Postcard 01 and 02 differ in palette values: `--paper` is `#F2EEE6` in 01 and `#F4F1EA` in 02, which is off-palette.
- `posters.html` is superseded but still on disk and still reads the same images.
- Stale statements: root `README.md` (Helvetica), `ferry/README.md` ("only the logo"), Ferry Sans README (serif display), `POSTER_GRIDS.md` (9:16, no superseded note), memory `ferry-sans` (display serif), `BRIEF.md` (Done list, watercolour).

**Fonts and licences.**
- Bodoni Moda, Monsieur La Doulaise and La Belle Aurore load from the Google Fonts CDN, not from disk. Offline or blocked renders fall back silently. `VOICES.md` lists the first two (SIL OFL) but not La Belle Aurore.
- La Belle Aurore is a placeholder for a real pen hand. No real handwriting has been written or scanned.
- Ferry Sans: GUST licence requires the rename and manifest. Both are done. The mark and wordmark are owned outright.

**Quality flags from the user.**
- First header scenes: too childish (superseded). Posters: good images, not modern enough. Mockups: first six fell short; the redesign rules exist but weren't applied. `system/system.html` was a Helvetica placeholder per memory but now uses Ferry Sans.

**Only in /private/tmp.**
- Nothing Ferry-related was found. No Ferry file contains a `/private/tmp` or `/tmp` path, and no Ferry-named file exists there. Other sessions' scratchpads under `/private/tmp/claude-501/` could not be tied to Ferry; treat them as unchecked.
